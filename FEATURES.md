# Dashboard Application — Feature Checklist

## Financial Overview
- [ ] Display total income summary
- [ ] Display total expenses summary
- [ ] Net balance calculation (income − expenses)
- [ ] Transaction history list (income & expenses)
- [ ] Add / edit / delete income entries
- [ ] Add / edit / delete expense entries
- [ ] Categorize expenses (e.g. food, rent, subscriptions)

## Crypto Portfolio
- [ ] Connect to exchange API(s) to fetch live portfolio data
- [ ] Display current holdings with live prices
- [ ] Display unrealized P&L per asset
- [ ] Display trade history fetched from API

## Crypto Trading
- [ ] Place a trade with a single button click
- [ ] Toggle between **Market** and **Limit** order types
- [ ] **Market order** — execute immediately at current price
- [ ] **Limit order** — set offset from market price
  - [ ] Enter offset as a fixed **amount** (above/below market)
  - [ ] Enter offset as a **percentage** (above/below market)
- [ ] Confirm dialog before submitting any order

## Body Metrics Tracker
- [ ] Log bodyweight entries over time
- [ ] Log waist measurements over time
- [ ] Log arm measurements over time
- [ ] Log thigh measurements over time
- [ ] View progress over time per metric (chart/graph)
